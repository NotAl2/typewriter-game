# Typewriter Game

A cozy 1870s typing game that slowly becomes an analog horror mystery, when a
simple mistake sends a letter to an address that doesn't exist.

See **[Game Concept & Design Document.md](Game%20Concept%20&%20Design%20Document.md)**
for the story, tone and long-term direction.

## What's built

**The Correspondence Ritual** — the game's core mechanic, as a complete playable
run. Four letters, each typed start to finish with the player performing every
physical step: feeding the sheet, typing it, throwing the carriage at the bell,
clearing the occasional typebar jam, getting the page out (wind it, or throw the
paper release), folding it, sealing the envelope with molten wax, and pressing
the rose.

Ruin a page and it becomes waste: crush it in your fist and throw it in the
basket. Send a poor letter and the next post brings a colder reply. Send enough
of them and a rage-filled letter arrives that ends the run — you read it, then
the dismissal notice comes up.

The start menu is itself a letter lying on the desk — a note of engagement with
the terms set out as a list you mark up: how much patience your clients have,
and whether to run the guide that walks you through the machine.

📖 **[RITUAL.md](RITUAL.md)** — controls, every step, all tuning constants,
architecture, and how to verify it.

🎨 **[ASSETS.md](ASSETS.md)** — the asset manifest and how to replace any of it.

## Running it

Open the project in Godot 4.7 and press F5, or:

```bash
godot --path .
```

Base resolution is 640×360 with integer scaling, so it lands pixel-perfect at 3×
on a 1080p display.

Pick a difficulty in the menu:

| Mode | Poor letters allowed |
|---|---|
| LENIENT | two warnings first |
| STANDARD | one warning, then dismissal |
| UNFORGIVING | the first poor letter ends it |

## Regenerating the art and audio

Every sprite, font and sound in this repo is generated by a script — there are no
binary assets that can't be rebuilt from source.

```bash
python tools/gen_art.py     # sprites, fonts, and scripts/Layout.gd
python tools/gen_audio.py   # all 29 sounds
godot --headless --path . --import
```

Requires Python 3 with `pillow` and `numpy`.

`tools/layout.py` holds every number the art and the code both need, and writes
them out to `scripts/Layout.gd`, so a sprite and the code that positions it can
never disagree.

## Tests

```bash
godot --headless --path . --fixed-fps 120 -- --test-ritual
```

Drives the real scene through the whole ritual with no player — including the
failure paths — and asserts **83 conditions**: the platen clamp that prevents the
scroll softlock, forgiving hitboxes, the crumple-and-bin loop, the paper
release, the wax stick burning away, and every difficulty's reply chain right
through to the rage letter.

Add `--capture-shots` and drop `--headless` to write a frame per stage to
`user://shots/`; `-- --capture-ui` photographs the menu, guide, results, reply
and dismissal screens.
